# Response-head own-record projection

The fixture is generated by executing Node Headers and the exact pinned
headersToRecord helper from pi-mono commit
853a80d26c90a14c1886f0ebb8ffaae133ca2185, not by Rust output.

Run the offline oracle with a sanitized environment:

```sh
env -i PATH=/usr/bin:/bin NODE_NO_WARNINGS=1 node conformance/provider-helpers/response-head/oracle.mjs
```

It covers lowercase duplicate joining, Cookie semicolon joining, final Set-Cookie,
whitespace trimming, Latin1, empty values, numeric own-key order, literal constructor,
and __proto__ producing no own key in the pinned plain object. The runtime constructor
leaves the raw transport headers intact. No prototype values or behavior are exposed.
