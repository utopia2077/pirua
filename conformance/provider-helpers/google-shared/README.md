and evaluates the unmodified function bodies. It imports the actual installed
`@google/genai 1.52.0` enums and ApiError, constructs no client, and uses injected
time/jitter/sleep. Source hashes and regex-derived export inventory are embedded.

## Preserved quirks and declared boundaries

- Schema sanitizer visits objects, including ordinary data objects/property names,
  but never arrays. Thus anyOf array metadata survives. It removes the eight
  listed meta keys at every visited object and preserves references.
  Plain-object __proto__ assignment creates no own key; Rust projects own values
  only without emulating prototypes. parametersJsonSchema remains unsanitized.
- Function mode resolution evaluates strict eligibility before none/any and
  short-circuits at the first strict tool, even if a later tool would reject.
- Base64 signature validation follows source shape/padding, not decoded pad bits.
  Empty signed text/thinking parts stay distinct. The helper's provider/model
  check ignores api, but the preceding shared transform is api-aware, exactly
  as in the source composition. No validator-bypass signature is invented.
- Claude/gpt-oss prefixes are case-sensitive; the Gemini major regex is not.
  Non-Gemini image results are nested according to executable source despite
  the nearby comment. Gemini below three adds a separate image turn that also
  splits later function-response merging.
- Foreign IDs replace each UTF-16 unit and truncate to 64 ASCII units. Same-model
  IDs remain unchanged. Accepted core collision rejection is retained rather
  than silently merging two IDs; that core normalization is explicitly tested.
- Existing core Tool/JsonObject canonical property order remains the input
  boundary. The oracle canonicalizes schema objects before strict conversion;
  numeric required-key order and array order remain observable. This is not
  preservation of arbitrary JS object insertion identity. Use shared wire JSON
  serialization for SDK bytes; durable numeric types/serialization are unchanged.
- Content projections are typed, transient, serialize-only SDK subsets, not a
  replacement durable schema or all SDK Part variants. Strings use core UTF-8:
  lone JS surrogates are not admitted. Synthetic transform time is caller-supplied.
  Tools retain shared strict-schema limits; a borrowed depth check plus shared
  wire serialization bounds unstrict schema conversion.
- Retry wraps the accepted generic full-attempt owner. ApiError explicitly means
  an Error with status but no headers; Provider already has valid metadata;
  Other covers non-Error/invalid provider shapes. Status is the existing transport
  Option<u16> projection, not arbitrary JS numeric/object identity. Opaque error
  values survive final and policy failures without Debug/Clone/Serde bounds.
  Attempts must disable lower retry and finish error bodies before rejection.
  Original caller cancellation drops noncooperative attempts/backoff. This is the
  already accepted stronger cancellation contract, not a claim that the source
  retry loop itself races a permanently pending promise.

The causal guard removes only the signed-empty text preservation condition:
`signed_empty_blocks_are_preserved_as_distinct_parts` fails with 2 parts versus
3. Restoring the guard restores the passing suite. No existing tests changed.
