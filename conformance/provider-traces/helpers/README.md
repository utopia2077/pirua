# Shared provider helper evidence

These fixtures are independently transcribed from pi-mono Git objects at
`853a80d26c90a14c1886f0ebb8ffaae133ca2185`. Evidence class is
**source-confirmed**, not an executed TypeScript differential trace. No expected
schema or event string is generated by the Rust implementation under test.

`strict-schema.json` binds to `strict_schema_source_fixtures` in
`crates/pi-ai-providers/tests/provider_helpers.rs`. The first case adapts
`packages/ai/test/constrained-sampling.test.ts:121` (nested optional/nullable
properties). Remaining cases derive from the complete
`packages/ai/src/api/constrained-sampling.ts` algorithm. Required-array order
uses JavaScript array-index ordering followed by the core's canonical non-index
key ordering. Core JsonObject already discarded original insertion order; this
is a named normalization, not a claim to recover it.

transport operation or built-in provider registration. No family is enabled by
default. The original S03 aggregate and cumulative export mapping are untouched;
