`family-oracle.mjs` executes the complete provider module and actual SDK

Core `JsonObject`/`JsonSchema` inputs enter the source oracle in their existing

## Malformed modeled-event JSON stage correction

`malformed-event-oracle.mjs` retains the independent review's eight controls and
eleven same-cause neighbors through the complete pinned wrapper and actual SDK.
The original 119 cases, including all 50 malformed HTTP cases, remain unchanged.

```sh
env -i PATH=/usr/bin:/bin NODE_NO_WARNINGS=1 node conformance/provider-traces/bedrock-converse-stream/malformed-event-oracle.mjs --check
```

Before the first modeled event resolves, Smithy's deserializer middleware adds
its fixed diagnostic suffix and response-body metadata; the provider can then
classify body fallback. Later iterator parsing bypasses that middleware and
exposes only JSON parser diagnostics. It must not classify the entire raw body.
The reader passes its existing priming state to both modeled and initial-response
parsing. Later errors derive safe classifier facts from the source's unexpected-
token preview (whole text through 20 UTF-16 units; otherwise the ten units on
either side of the parser position) or numeric diagnostic position/line/column.
Unfinished values and empty-array EOF use the distinct no-position diagnostic.
These facts are consumed before fixed redacted failure publication; no native
exception prose, new public error field, parser acceptance rule or limit changes.

Named controls retain long-tail retry/overflow words outside the preview, short
and internal previews, 20/21-unit boundaries, numeric syntax diagnostics and
position-bearing versus position-free EOF, and CR diagnostic line counting. An intentional mutation restoring
raw-body classification reproduces both independent failures while preserving
the priming neighbor. Request counts, Start/terminal shape, request-id diagnostics,
body release and all original event/body/signature assertions stay checked.
